# 🎓 五邑大学自动评教助手 (WYU Auto Eval) v10.0

专为五邑大学教务系统设计的自动评教 Chrome 扩展。拒绝繁琐的手动点击，一键释放双手！

![自动评教](https://img.shields.io/badge/%E7%8A%B6%E6%80%81-%E7%A8%B3%E5%AE%9A%E7%89%88-green) ![版本](https://img.shields.io/badge/Version-v10.0-blue)

## ✨ 核心功能

- **🚀 一键全自动**：自动遍历所有未评教课程，无需逐个点击。
- **🛡️ 极度稳定 (v10)**：采用 **“单次评教+自动刷新”** 策略，彻底解决“页面失效”、“滑块卡死”和“白屏”问题。
- **🕵️ 防 WAF 检测**：内置**随机延迟**机制，模拟真人操作频率（忽快忽慢），避免触发服务器 491 封禁。
- **🎨 优雅交互**：
  - **悬浮面板**：可随意拖动，不遮挡视线。
  - **极简模式**：可折叠成小圆球，保持页面整洁。
  - **状态记忆**：自动保存面板位置和折叠状态。
- **⚡ 智能容错**：自动识别滑块验证、自动重试、自动跳过已评课程。

## � 安装指南

1.  **下载代码**：点击右上角 `Code` -> `Download ZIP` 下载本仓库压缩包并解压。
2.  **打开扩展管理**：在 Edge 浏览器地址栏输入 `edge://extensions/`。
3.  **开启开发者模式**：打开左侧边栏的“开发人员模式”开关。
4.  **加载扩展**：点击“加载解压缩的扩展”，选择解压后的文件夹。

## 🎮 使用方法

1.  登录 [五邑大学教务系统](https://jxgl.wyu.edu.cn/)。
2.  进入 **“评价信息” -> “学生评教”** 页面。
3.  页面会自动出现紫色的 **“自动评教”** 悬浮面板。
4.  点击 **“🚀 一键评教”** 按钮。
5.  喝杯咖啡 ☕️，脚本会自动完成所有课程的评价（每评完一个会自动刷新页面，请勿关闭）。

## ⚠️ 注意事项

- **保持页面前台**：评教过程中建议保持浏览器窗口在最前台，以免系统休眠导致脚本暂停。
- **数据安全**：本脚本仅在本地运行，不会上传任何个人账号信息。
